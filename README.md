# JARVIS Galaxy

Last ned **[den lille installatøren (0,17 MB)](https://github.com/Julikaan/jarvis-galaxy-releases/releases/download/v0.4.0/JARVIS-Galaxy-Web-Setup-0.4.0-Windows.exe)** og dobbeltklikk den. Den henter Windows-pakken på 105,3 MB, kontrollerer størrelse og SHA-256 og åpner den vanlige installasjonsveiviseren. Etter installasjon åpner du JARVIS fra Start-menyen.

Vil du installere uten en ekstra nedlasting, velg **[hele Windows-pakken](https://github.com/Julikaan/jarvis-galaxy-releases/releases/download/v0.4.0/JARVIS-Galaxy-Setup-0.4.0-Windows.exe)**.

JARVIS Galaxy har en interaktiv 3D-galakse med solen som leder, jorden og Jupiter: første klikk zoomer, andre klikk åpner funksjonene. Chat, oppgavetavle, prosjekter, Vault, fokusklokke og offentlig GitHub-/HTTPS-lesing er inkludert.

For Windows 10/11 x64. Den lille installatøren bruker .NET Framework 4.8 og trenger internett. Fullpakken inneholder programmets runtime; Node.js og separat nettleser er ikke nødvendig. Installering skjer for Windows-brukeren din. Dette er en usignert utviklingsutgave.

Lokale funksjoner virker uten modellkonto. GPT-6.1 Sol/ultra via Codex eller OpenAI og Claude Code trenger eget oppsett på hver PC. Claude-broen gir planer og svar; skills/plugins og selvstendig filarbeid er deaktivert i denne utgaven. Tale er foreløpig en plassholder.

Ingen API-nøkler, kontoinnlogging eller brukerdata følger med. Dette distribusjonsrepoet inneholder bare veiledning og installasjonsfiler. SHA256.txt gir kontrollsummene for begge EXE-filene.
